Consensus: What All 4 Reviewers Agreed On

Unanimous Strengths
  • Two-pass extraction is the right architecture — deterministic hints reduce hallucination and cost. All 4 reviewers praised this.
  • Configurable profiles create real differentiation — VC/Legal, General, and Crypto presets serve distinct markets. Nobody in the newsletter space does this.
  • Module separation is clean — 6 new files, zero existing files modified. Integration is surgical. Easy to roll back.
Unanimous Concerns
  • No extraction rate limiting / quotas — Users can trigger unlimited Claude API calls. Cost explosion risk + DoS vector. (Flagged by CEO, Eng, Security, DX)
  • Extraction blocks on long newsletters — 30+ second API calls with no progress feedback. Frontend will timeout. (Flagged by Eng, DX)
  • Free tier won't drive conversion — Stats-only teaser shows volume, not value. Users won't feel compelled to upgrade. (Flagged by CEO, DX)

Chairman's Synthesis: Priority Fixes Before Ship

CRITICAL Fix Before Any Users Touch This

1
Prompt Injection Protection Security
Newsletter content flows into Claude prompts. A malicious newsletter can inject </user_content> to hijack extraction. Escape angle brackets and add a secondary fence.
File: graph-ai.js line 51 · Effort: 2 hours
2
Extraction Rate Limits + Quotas Security Product
Add per-user monthly extraction limits: Free=0, Standard=20/mo, Premium=unlimited. Prevents cost explosion AND drives upgrades.
File: graph-routes.js · Effort: 3 hours
3
Transaction Safety for Merge/Delete Eng
mergeNodes() runs 6 DB operations without a transaction. Server crash mid-merge = corrupted graph. Wrap in BEGIN/COMMIT.
File: graph-service.js lines 475-540 · Effort: 1 hour

HIGH Fix Before Public Launch

4
Async Extraction with Progress DX Eng
POST /extract blocks for 30+ seconds. Return a task ID immediately, let frontend poll for progress. Otherwise the UI will feel broken.
Files: graph-routes.js, graph-extractor.js · Effort: 4 hours
5
Entity Resolution Race Condition Eng
Between SELECT and INSERT in resolveEntity(), another process can create the same entity → duplicates. Use ON CONFLICT DO UPDATE.
File: graph-service.js lines 23-87 · Effort: 2 hours
6
Free Tier: Sample Entity Detail (not just stats) Product
Let free users click into ONE entity and see full connections. "Sequoia Capital → 12 companies, 8 people." Then lock the rest behind Standard. This is the conversion hook.
File: graph-routes.js (new endpoint) · Effort: 2 hours

MEDIUM Fix Before Scale (100+ users)

7
Batch Entity Resolution (N+1 fix) Eng
Entity loop does 3 DB queries per entity × 100 entities = 300 queries per newsletter. Batch into single SELECT.
8
Extraction Retry Queue Eng
When Claude API fails, extraction silently returns empty. Add an extraction_queue table to retry failed jobs.
9
Community Detection Chunking Eng
Current algorithm loads ALL nodes. Add a 10K node limit and run as background job for large graphs.
10
Confidence Scoring Product
Add confidence field to entities. Show users "82% certain" vs graying out low-confidence entities. Builds trust for legal/VC users.
11
Relationship Type Filtering DX
API can't filter by relationship type or hide inferred edges. Add ?relationships=invested_in&includeInferred=false params.
