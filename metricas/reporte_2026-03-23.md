## Datos necesarios para activar el reporte automático

Para que el agente pueda generar métricas reales, se necesita **una** de las siguientes opciones:

### Opción A — Archivo CSV semanal (más simple)
Depositar un archivo `datos_semana.csv` en esta carpeta (`/brevis/metricas/`) con el siguiente formato:

```
fecha,mrr_usd,usuarios_activos,nuevos_registros,churn
2026-03-23,0,0,0,0
```

### Opción B — Conectar Stripe MCP
Instalar el plugin de Stripe en Cowork para que el agente pueda consultar directamente:
- Suscripciones activas → MRR
- Clientes creados esta semana → Nuevos registros
- Suscripciones canceladas → Churn

### Opción C — Exportación desde Railway/PostgreSQL
Exportar semanalmente los datos de la tabla `users` como CSV:
```sql
SELECT
  COUNT(*) FILTER (WHERE is_active = 1) AS usuarios_activos,
  COUNT(*) FILTER (WHERE created_at >= NOW() - INTERVAL '7 days') AS nuevos_registros,
  COUNT(*) FILTER (WHERE is_active = 0 AND updated_at >= NOW() - INTERVAL '7 days') AS churn
FROM users;
```
