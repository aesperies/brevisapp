CRITICAL FINDINGS (MUST FIX)
================================================================================

1. PROMPT INJECTION VULNERABILITY [CRITICAL]
   File: graph-ai.js, line 51
   Problem: Newsletter content flows into Claude prompt with minimal escaping
   Impact: Attacker can hijack extraction, manipulate entity extraction results
   Fix: Character escaping + prompt fencing + structured output
   Effort: 2-3 hours

2. UNLIMITED EXTRACTION RATE LIMITING [HIGH]
   File: graph-routes.js, lines 201 & 221
   Problem: No per-user rate limits on extraction endpoints
   Impact: User can burn $1000+ in Claude API costs per day
   Fix: Add express-rate-limit middleware + daily quota tracking
   Effort: 2 hours

3. MISSING EXTRACTED DATA VALIDATION [HIGH]
   File: graph-extractor.js, lines 119-172
   Problem: No caps on entity/relationship counts from LLM
   Impact: Database bloat, memory exhaustion, DoS
   Fix: Add validation function, cap at 500 entities/1000 relationships per newsletter
   Effort: 2 hours

================================================================================
HIGH PRIORITY FIXES (DO BEFORE STANDARD TIER)
================================================================================

4. Missing Newsletter Size Limit [MEDIUM]
   File: graph-ai.js
   Problem: No max file size before processing
   Impact: Large HTML could crash extraction
   Fix: Add 10MB max size check
   Effort: 1 hour

5. Batch Extraction Input Validation [MEDIUM]
   File: graph-routes.js, line 221
   Problem: offset parameter unbounded
   Impact: Integer overflow edge case

   ✓ Safe - User A cannot access User B's data
